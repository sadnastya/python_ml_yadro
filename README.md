### HW 3 — Сжатие языковой модели (`HW_3.ipynb`)

Реализация комбинированного алгоритма **сжатия матриц весов** нейронных сетей без использования `numpy`.

**Этапы:**
1. **Квантизация** — преобразование весов с плавающей точкой в целые числа с заданным числом бит.
2. **Кодирование Хаффмана** — построение кодового дерева и сжатие квантованных значений.
3. **Бит-паккинг** — упаковка битов в байты для компактного хранения.
4. **Запись / чтение файла** — сохранение сжатых данных и их восстановление.

Также реализована обратная процедура — **распаковка и декодирование** сжатой матрицы.

## Финальный проект — Molecules API (`project/`)

REST API-сервис для работы с **молекулами**, реализованный с помощью **FastAPI** + **PostgreSQL** + **SQLAlchemy** + **RDKit**.

### Функциональность

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/molecules` | Получить список всех молекул |
| `GET` | `/molecules/{id}` | Получить молекулу по ID |
| `POST` | `/molecules` | Добавить новую молекулу (SMILES) |
| `PATCH` | `/molecules/{id}` | Обновить молекулу |
| `DELETE` | `/molecules/{id}` | Удалить молекулу |
| `GET` | `/search?substructure=...` | Поиск молекул по подструктуре (SMILES) |

Поиск по подструктуре реализован с помощью библиотеки **RDKit** (`HasSubstructMatch`).

### Архитектура

```
project/
├── src/
│   ├── main.py          # FastAPI-приложение, роуты
│   ├── models.py        # SQLAlchemy-модель Molecule
│   ├── schemas.py       # Pydantic-схемы (валидация запросов/ответов)
│   ├── repositories.py  # Слой доступа к данным (CRUD через SQLAlchemy Session)
│   └── dependencies.py  # Dependency injection (get_molecule_repository)
├── alembic/             # Миграции базы данных (Alembic)
├── nginx/               # Конфигурация Nginx (балансировщик нагрузки)
├── Dockerfile
├── docker-compose.yaml
└── requirements.txt
```

### Инфраструктура (Docker Compose)

- **web1 / web2** — два экземпляра FastAPI-приложения (uvicorn) для горизонтального масштабирования.
- **nginx** — балансировщик нагрузки между `web1` и `web2`, слушает порт `80`.
- **db** — PostgreSQL 16, хранит данные в именованном volume `db_data`.

### Стек технологий

`FastAPI` · `SQLAlchemy` · `Alembic` · `PostgreSQL` · `RDKit` · `Pydantic` · `Docker` · `Nginx`

### Запуск локально

```bash
fastapi dev ./src/main.py
```

### Запуск в Docker

```bash
docker compose up --build
```
